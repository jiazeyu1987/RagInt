# 展厅讲解稿生成提示词

> 用途：用于 LLM 生成各展厅重点产品的讲解稿
> 更新日期：2026 年 3 月

---

## 使用说明

将以下提示词复制到大模型对话框中，即可生成对应展厅的讲解稿。讲解稿适合用于：
- 展厅现场讲解
- 语音导览播放
- 客户参观介绍
- 培训材料

```
- 产品数量：25 个
- 主要公司：瑛泰医疗
- 产品类别：心脏介入手术基础耗材

【重点产品及亮点】
1. 血管鞘（序号 7-11）：介入手术中第一个进入人体、最后一个离开人体的器械，手术时长 2-4 小时不能渗血，技术要求极高
2. 球囊扩张压力泵（序号 12-15）：与贝朗合作 14 年，贝朗在欧洲所有的压力泵 Y 阀都是瑛泰生产，2022 年被评为年度最好用压力泵

【讲解要求】
- 开场白：欢迎词 + 展厅定位（瑛泰从心脏介入低值耗材起家）

- 融入技术难点和临床意义（如血管鞘不能渗血对手术的影响）
- 体现与跨国企业合作 14-15 年的外贸出口基因
- 结束语：引导至下一个展厅
- 总时长：8-10 分钟
- 语言风格：专业但不失亲和力，避免过多医学术语

【背景信息】
瑛泰医疗是从心脏介入植入的低端耗材起家的，当时国内该领域大部分依赖进口。瑛泰是国内第二家真正从这个领域开始完全覆盖的公司。通过低值产品完成技术储备，2018 年成为中国介入耗材出口量最大的企业。
```

### 展厅提示词

```
你是一名专业的医疗器械展厅讲解员。请为"心脏植入展厅"撰写一份讲解稿。

4. PFA 脉冲电场消融导管（序号 41-44，德诺电生理）：中国第一个拿证的花瓣状脉冲电场消融导管
5. TAVR 瓣膜（序号 45-49，翰凌医疗）：2017 年启动，2023 年底完成临床，已提交国家局，经股动脉球扩方式，3 个镍钛定位角自动定位，手术时间<7 分钟，可回收

【讲解要求】
- 开场白：承接上一展厅，说明本展厅是"高端心脏介入产品"
- 重点介绍上述 6 类重点产品，突出技术突破和临床价值
- 强调"国产替代"和"国际领先"（如造影导管零事故、药球 62 天药物浓度）
- TAVR 和镁合金支架要突出研发周期长（5-8 年）、技术难度大
- 结束语：引导至外周介植入展厅
- 总时长：12-15 分钟
- 语言风格：专业、自信，体现技术实力

【背景信息】
瑛泰通过低值耗材完成技术积累后，进军高端心脏介入领域。造影导管曾长期依赖进口，2015 年掌握完整工艺后实现国产突破。TAVR 项目与美敦力球扩瓣竞争，但有自主专利。镁合金支架是全球首个无铝无稀土配方，技术难度极高。
```

## 10. 公司与孵化转化平台介绍

### 展厅提示词

```
这是一份展厅讲解稿撰写任务，请生成用于语音播报的讲解稿正文。

你是一名专业的医疗器械展厅讲解员，正在为参观者录制展厅讲解音频。本展厅是"公司与孵化转化平台介绍"，是了解瑛泰的第一站。

【展厅概况】
- 展厅位置：入口序厅
- 展厅主题：公司整体介绍、孵化平台理念、子公司布局
- 核心内容：平台赋能模式、子公司矩阵、产业基地
- 核心理念："筑巢引凤"、"一口锅里吃饭"

【重点内容及亮点】
1. 孵化平台理念：初创公司缺的不仅是资金，还有创业资源和经验；平台提供资金 + 行业资源赋能 + 创业经验分享 + 内部资源协同
2. 子公司矩阵：已孵化近 20 家子公司，瑛泰 50% 以上绝对控股，覆盖心脏介入、神经介入、外周介入、骨科、泌尿、医美、消费医疗等领域
3. "一口锅里吃饭"的平台文化：必须在同一个平台上，有分享机制，对子公司赋能，把瑛泰集团做大
4. 三大产业基地：
   - 上海嘉定总部：52,000㎡，2019 年买下第一地块，2023 年 5 月搬入新大楼
   - 山东日照基地：48,000㎡，2024 年正式开园，定位化妆品和保健品
   - 珠海基地：非介入类医疗器械制造
5. "筑巢引凤"策略：房子和地不是搞房地产，而是用于内部企业孵化；每个园区都有空间、硬件、实验室、资源赋能

【讲解要求】
- 开场白：欢迎词，说明本展厅是"了解瑛泰的第一站"
- 重点解释"孵化平台"模式与单纯投资的区别（资源赋能 vs 只给资金）
- 说明"50% 绝对控股"的治理结构优势（统一战略、资源共享）
- 三大基地要突出"不是房地产，是孵化载体"的定位
- 用"筑巢引凤"的比喻说明平台的吸引力
- 结束语：引导至各产品展厅
- 总时长：8-10 分钟
- 语言风格：大气、有格局，体现企业家的战略思维

【背景信息】
瑛泰的孵化平台理念源于创始人对初创公司的理解：缺的不仅仅是资金，更多的是创业的资源以及创业的经验。为了让初创公司少走弯路、少踩坑，平台不仅提供资金，更提供行业资源赋能、创业经验分享、内部资源协同。所有子公司都是 50% 以上绝对控股，目的是"把盘子做大"，让大家"在一口锅里吃饭"。园区的房子都是用于内部企业孵化，没有对外招租，靠租金不是目的，赋能能力才是核心。上海嘉定总部 52,000㎡到现在几乎没有空的地方，说明产能扩张需求大。山东日照 48,000㎡2024 年开园，定位化妆品和保健品，是消费医疗的布局。
```
