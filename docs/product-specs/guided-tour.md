# Guided Tour

## 场景定义

Guided Tour 面向“按展位/站点连续讲解”的场景，比单次问答更强调节奏、接续和复用。

## 当前三种模式

- 实时讲解：实时调用问答/TTS 生成当前站点内容
- 录制讲解：实时生成，同时把文本片段与音频沉淀为录制资产
- 回放讲解：直接复用已存档的讲解资产

## 关键前端能力

- `tour` 状态管理
- 站点跳转、继续、重置
- 录制开关与回放开关
- 模板、画像、讲解风格、时长和目标字数设置
- 唤醒词与语音连续对话配置

## 关键后端能力

- `/api/tour/templates`: 读取导览模板
- `/api/tour/plan`: 生成导览站点计划
- `/api/tour/control` / `/api/tour/control/consume`: 导览控制命令总线
- `/api/tour/command/parse`: 自然语言导览控制解析
- `recordings` API: 录制资产管理

## 成功体验

- 开始讲解后，系统知道当前站点、讲解模式和当前节奏。
- 用户插问时可以打断当前讲解。
- 回答结束后可以继续原导览，而不是重新从头开始。
- 录制后的讲解可以被点选、重命名、删除和回放。

## 产品边界

- 当前导览仍以单前端应用内的状态编排为主。
- 设备控制和 ops 是辅助能力，不是导览规格本身的替代品。
